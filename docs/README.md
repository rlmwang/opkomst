# Docs

Opkomst is a privacy-first sign-up tool for volunteer organising. It
makes six things: events, questionnaires, quizzes, kompassen, date
polls and chore rosters. Somebody who opens one of its links never
makes an account, and the app forgets what it does not need.

**Start here**

- `architecture.md`, how the app is wired.
- `principles-architecture.md` and `principles-ux.md`, the rules the
  code converges on.

**The products**

- `design-recurring-events.md`, events and the dates they produce.
- `design-quizzes.md` and `design-kompas.md`, the two products that are
  a questionnaire with something extra.
- `design-datepolls.md`, `design-chores.md`.
- `design-edit-link.md`, how somebody gets back to what they sent.
- `design-public-pages-ux.md`, the one grammar all six share.

**Accounts and organisations**

- `design-personal-tenants.md`, the account anyone can make.
- `design-tenants-and-branding.md`, how an organisation is added.
- `design-paywall.md`, what the free tier does and does not send.

**Running it**

- `deploy.md` for a VPS, `deploy-raspberry-pi.md` for a home server.
- `runbook.md` when something is wrong.
